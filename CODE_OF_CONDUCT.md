# Code of Conduct

This project adopts the HEP Software Foundation (HSF) community standards. All
participants — contributors, mentors, and reviewers — are expected to engage
respectfully and constructively, ask questions openly, and help newcomers.

Harassment or exclusionary behaviour of any kind is not tolerated.

For the full HSF community guidelines, see
https://hepsoftwarefoundation.org/. To report a concern, contact your GSoC
mentor or the HSF GSoC admins at hsf-gsoc-admin@googlegroups.com.
